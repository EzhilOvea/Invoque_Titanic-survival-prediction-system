# Invoque_Titanic-survival-prediction-system
# Titanic Survival Prediction using Machine Learning

## Project Description
This project predicts whether a passenger survived the Titanic disaster using machine learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
The Titanic dataset (`train.csv`) contains passenger details such as age, sex, passenger class, fare, and survival status.

## Steps Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- Model training and comparison
- Model evaluation
- Survival prediction

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
